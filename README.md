# 知析小伴 ZhiXi Agent — 鸿蒙全场景学习陪伴 Agent

面向【鸿蒙高校创新赛 · 赛题2 Agent创新】的个人视频知识生成与学习陪伴智能体。

知析小伴将用户在 B 站收藏或导入的学习视频转化为可检索、可追踪、可复习的个人知识系统，并通过「小映 Agent」结合时间、学习进度、历史对话和设备场景，主动提供复习提醒、学习路径、边看边问、知识对战和多端学习陪伴。

## 赛题适配

- **竞赛方向**：鸿蒙高校创新赛 · Agent创新
- **作品名称**：知析小伴 ZhiXi Agent
- **核心定位**：从个人视频资源出发，构建具备长期记忆、主动服务和自然交互能力的鸿蒙全场景学习陪伴 Agent。

| 赛题要求 | 知析小伴适配方式 |
| --- | --- |
| 个人日常生活与陪伴 | 小映记住用户学习目标、薄弱点、学习偏好和复习历史，提供持续学习陪伴。 |
| 主动服务 | 根据时间、学习进度、收藏变化和复习状态，主动触发晚间复习、碎片时间学习、考前冲刺提醒。 |
| 自然交互 | 支持文本问答、语音问小映、边看边问、证据引用回答和小艺式指令入口。 |
| 鸿蒙全场景 | 设计手机、平板、手表、耳机、智慧屏不同交互形态，并支持元服务/服务卡片概念。 |

## 核心功能

- **小映 Agent**：围绕用户知识树进行问答、解释、总结、学习建议生成，并返回可追溯证据。
- **陪伴 Agent 工作台**：展示今日学习建议、学习画像、薄弱点、推荐动作和小艺式语音指令。
- **主动服务中心**：模拟时间、场景、学习状态和设备上下文，展示 Agent 主动判断链。
- **鸿蒙全场景体验**：展示手机、平板、手表、耳机、智慧屏上的学习 Agent 交互设计。
- **视频知识编译**：从视频字幕、标题和内容中抽取知识点、论断、章节和证据片段。
- **知识树与学习路径**：将视频内容组织为结构化知识图谱，支持多模式学习路径规划。
- **记忆与复习**：沉淀学习记录、掌握度反馈和复习任务，形成持续学习闭环。
- **知识对战**：基于知识树生成题目，用正确率和连胜反馈掌握状态。

## 小艺开放平台接入设计

知析小伴可作为小艺开放平台 Agent / Skills 的后端能力源：

```text
小艺语音唤醒
  ↓
意图识别：复习 / 学习路径 / 视频问答 / 知识对战 / 收藏导入
  ↓
调用知析后端 Agent API
  ↓
返回文字、语音、卡片或跳转动作
  ↓
更新用户学习画像与复习记录
```

示例指令：

- 「小艺小艺，帮我复习昨天看的视频」
- 「小艺小艺，今天我该学什么？」
- 「小艺小艺，用三分钟讲懂注意力机制」
- 「小艺小艺，问我几道知识对战题」

## 技术架构

```text
用户视频资源 / 学习上下文 / 鸿蒙设备场景
  |
  v
B 站收藏 / 视频合集 / 单视频 / 小艺语音指令
  |
  v
内容获取层：字幕、标题、分 P 信息、ASR 兜底
  |
  v
知识编译层：大模型 + 规则过滤 + 证据校验
  |
  v

  |
  v
Agent 编排层：意图识别 / 主动服务 / 学习画像 / 工具选择
  |
  v
鸿蒙全场景体验：手机对话 / 平板图谱 / 手表闪卡 / 耳机语音 / 智慧屏展示
```

## 技术栈

| 模块 | 技术 |
| --- | --- |
| 前端 | Next.js 16, React 19, TypeScript, Tailwind CSS |

## 本地运行

### 1. 后端

```bash
pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### 2. 前端

```bash
cd frontend
npm install
npm run dev
```

默认访问：

- 前端页面：`http://localhost:3000`
- 后端接口：`http://localhost:8000`
- API 文档：`http://localhost:8000/docs`

## 作品亮点

- 从视频收藏出发构建个人知识 Agent，而不是普通聊天机器人。
- 回答绑定知识点、论断、章节和视频证据，降低大模型幻觉。
- 主动服务结合时间、学习进度和设备上下文，在合适时刻出现。
- 面向鸿蒙全场景设计手机、平板、手表、耳机、智慧屏体验。
- 学习画像、记忆系统、复习任务和知识对战形成长期陪伴闭环。
